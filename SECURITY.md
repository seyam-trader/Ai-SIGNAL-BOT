# Security checklist

- Keep repository private.
- Never commit API keys.
- Never hardcode admin passwords.
- Use server-side password hashing.
- Use device-bound sessions where appropriate.
- Allow admin to revoke sessions/devices.
- Validate every server request.
- Treat the client APK as untrusted.
- Do not assume APK obfuscation is a security boundary.
- Do not store raw screen/camera frames unless necessary.
