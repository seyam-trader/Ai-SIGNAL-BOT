# Build guide

1. Install Android Studio.
2. Open this repository as an Android project.
3. Let Gradle sync.
4. Connect an Android device or create an emulator.
5. Run the `app` configuration.
6. Grant overlay permission when prompted.
7. Grant screen-capture permission when requested.
8. For camera mode, grant CAMERA permission.

For GitHub:
- Create a private repository.
- Upload the extracted project files, not only the ZIP archive.
- Never commit secrets.
